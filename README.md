# Student Management System (C++)

## Overview
This is a C++ program that manages student records including:
- Name and ID
- Grades (3 subjects, 2 exams each)

## Features
- Input validation with exception handling
- Display student details
- Calculate averages
- Find highest scoring student
- Update student grades
- Class subject averages
- Sorting by average

## Technologies Used
- C++
- OOP (Classes)
- STL (vector, algorithm)

## How to Run
1. Compile:
   g++ main.cpp -o app
2. Run:
   ./app
